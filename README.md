# Selection Fashion World

Static frontend demo for GitHub + Vercel.

## Included
- Product catalog and filters
- Cart
- WhatsApp order creation
- UPI / COD selection
- SHA-256 frontend admin password check
- Admin orders/products/delivery-boy panels
- COD payment collected flow

## Important
This is a frontend-only demo. localStorage is used for data and is NOT a secure cloud database. The admin password hash is not a substitute for server-side authentication. Do not use this version for real payment verification or sensitive customer data without a backend.

Default admin password: `SELECTION7812`

For real UPI payments, use a payment gateway and verify payments server-side.
